Para mover tool a otro ordenador:
1. Copias la carpeta "ai-trader" entera (sin .venv)
2. Instalas Python + Poetry
3. Ejecutas en PowerShell (desde carpeta donde se guarde): poetry install

Para ejecutar:
- Ir a la ruta de ai-trader en PowerShell
- Ejecutar "venv\Scripts\Activate.ps1"
- Ejecutar "python -m ai_trader.bots.telegram_bot"
